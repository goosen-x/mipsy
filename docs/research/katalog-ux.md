# Каталоги людей: UX-разбор для карточек психологов

**Решение 16.08.2026:** из трёх собранных вариантов выбран «список с досье»
(референс Ясно) — внедрён в `/catalog`: вертикальный список, портрет 208×240,
бейдж «Диплом проверен», строка «о себе», 3 темы + «и ещё N», правая колонка
решения (цена → рейтинг → ближайшее окно → кнопка), сортировка по ближайшему
свободному окну. Служебное превью `/preview/catalog` удалено.

Снято 2026-08-15. Материал для редизайна каталога mipsy (https://mipsy.mskacademy.ru/catalog — сейчас сетка 3 колонки, фото 56×56 слева от имени, подход, опыт/цена, 3 темы-чипа, рейтинг; фильтры-чипы сверху). Запрос: крупные квадратные фото + лучшие практики каталогов, где выбирают человека, а не товар.

Метод: смотрели живые публичные страницы (часть сайтов закрыта от ботов — такие места помечены «частично» с указанием источника-замены: кейс-стади, help-центры, архивные разборы).

## Каталоги терапевтов

### Ясно — yasno.live/therapists (главный референс)

Публичный каталог есть (кроме анкеты-подбора: «Кроме автоматического подбора, у нас есть и ручной»). Карточка — самая близкая к тому, что нужно mipsy:

- **Фото**: прямоугольное с закруглёнными углами, среднее/крупное — не аватарка.
- **Поля по порядку**: имя (ссылка) → бейдж **«Диплом проверен»** → «Опыт N лет» → **«Сессия 50 мин 3 150 ₽»** → вкладки «Основное» / «О себе» прямо на карточке → «Психотерапевтический подход» → «Работает с темами»: 4 видимые темы + **«и ещё 15»** → кнопка «Смотреть полный профиль».
- **Доступность прямо на карточке**: рядом с кнопкой профиля — **«12 слотов с 17 авг. 15:00»**. Ближайший слот и количество слотов видны без клика.
- **Пример карточки целиком**: «Наталья Андреева · Диплом проверен · Опыт 4 года · Сессия 50 мин 3 150₽ · Психоаналитическая терапия · Тяжёлое эмоциональное состояние, С родителями, Нестабильная самооценка, С партнёром и ещё 15 · [Смотреть полный профиль · 12 слотов с 17 авг. 15:00]».
- **Фильтры слева** (сайдбар): симптомы, подход, цена, пол + расширенные (опыт, возраст, методология).
- **Сигналы доверия на уровне платформы**: «Только 9% специалистов проходят отбор», «9 лет средний опыт практики», «81% клиентов чувствуют результат после 5-й сессии».
- **По клику** — полный профиль, запись оттуда.

Ссылки: https://yasno.live/therapists, https://yasno.live/

### Psychology Today — psychologytoday.com/us/therapists

Крупнейший каталог терапевтов в мире. Смотрели листинг Нью-Йорка:

- **Список, не сетка**: вертикальный список карточек во всю ширину; фото — портретный прямоугольник ~80–100px слева, текст справа.
- **Поля по порядку**: имя + регалии (например «Samantha Paige Madalon, MHC-LP, CASAC-T, EMDR») → бейдж **Verified** → счётчик эндорсментов от коллег («10 Endorsed») → статус доступности («Online Only», «Waitlist for new clients») → **личное заявление на 2–3 предложения** (главный текст карточки) → телефон.
- **CTA на карточке**: email, телефон (tel:-ссылка), «View» в профиль. Записи на слот нет — модель «свяжитесь сами».
- **Фильтры — левый сайдбар**, десятки измерений: пол, формат (In Person / Online), этничность, язык, вера, 60+ специализаций, 50+ методов, 100+ страховок, цена ($ <90 / $$ 90–130 / $$$ >130 / Sliding Scale), возрастные группы клиентов.
- **По клику** — профиль.

Вывод: карточка построена вокруг текста-обращения от первого лица, а не вокруг регалий; доверие — через Verified и эндорсменты коллег.

Ссылка: https://www.psychologytoday.com/us/therapists/ny/new-york

### Zocdoc — zocdoc.com (частично: прямой доступ закрыт, данные из кейс-стади и автоматизационной документации)

Эталон «слот решает»:

- Карточка врача: имя + степень (заголовок), специализация, расстояние («0.4 mi»), рейтинг + число отзывов, страховки («Accepts most plans»).
- **Доступность — главный элемент карточки**: чип «ближайшая дата» + **3–6 кнопок конкретных времён на эту дату** прямо в результатах поиска, остальные за «Show more». Клик по времени сразу стартует букинг (не профиль!).
- Кейс-стади: «Booking an appointment is incredibly easy. I can swipe for date availability and tap for time» — свайп по датам, тап по времени, от главного экрана до списка врачей «менее чем за 30 секунд».
- Гранулярные фильтры: специализация, локация, страховка + план, день, тип визита (очно/видео).

Ссылки: https://browse.sh/skills/zocdoc.com/find-appointment-ekztri (задокументированная структура выдачи), https://usabilitygeek.com/ux-case-study-zocdoc-mobile-app/

### Alter — alter.ru/psychologists

Каталог — SPA, карточки ботам не отдаёт; фильтры и платформенные сигналы сняли с отрендеренной версии, поля профиля — из независимого обзора.

- **Фильтры — самые богатые из русскоязычных**: город, формат, **время сессии с пометкой спроса («высокий спрос» у 07:00, 08:00, 16:00, 17:00)**, специализация (взрослые/семьи/дети, по 40+ тем), 25+ методов (КПТ, DBT, ACT, EMDR…), цена 0–20 000, возраст специалиста 18–99, пол, семейное положение, наличие детей, «чувствительность» (ЛГБТ+, феминистская оптика, работа с верующими, онкопациентами).
- Редкая честность в UI каталога: «Умение вас услышать и понять зависит от квалификации специалиста, а не от его личного опыта» — прямо отговаривают фильтровать по полу/семейному статусу.
- Профиль: образование, подходы, опыт, темы, цена, город/онлайн + **аудио «послушать голос психолога»** — уникальный приём снятия тревоги перед первой сессией.
- Платформенные сигналы: «1 000+ проверенных психологов», «615 000+ проведённых сессий с 2017 года», «8,9/10 средняя оценка качества терапии», «90% клиентов нашли подходящего психолога с первого раза»; отбор — дипломы, тестирование, интервью, проверка часов супервизии и личной терапии.

Ссылки: https://alter.ru/psychologists, https://alter.ru/, https://vc.ru/services/2919586-servis-alter-otzyvy-plyusy-i-minusy-podbora-psikhologov

### B17.ru (частично: сайт отдаёт 429/капчу ботам)

Прямо снять карточку не удалось (капча «Подтвердите, что запросы отправляете вы, а не робот»). По отзывам и публичным описаниям: гигантский список анкет с поиском по городу/специализации, демо-консультации на форуме как способ «пощупать» специалиста до записи, рейтинг и «топы». Важный анти-сигнал из отзывов: **«топ-100 и топ-50 покупаются»** — рейтинг, в который можно заплатить, перестаёт быть сигналом доверия и вызывает обратную реакцию.

Ссылки: https://www.b17.ru/psiholog/, https://otzovik.com/reviews/b17_ru-sayt_besplatnoy_psihologicheskoy_pomoschi/, https://irecommend.ru/content/b17ru-besplatnye-konsultatsii-psikhologov

### Профи.ру — profi.ru/repetitor/psihologia/web/

Каталог «Психологи онлайн — 3674 психолога, 340 отзывов, цены от 1500 рублей/ч и рейтинг»:

- **Фото**: круглый аватар ~90×90 — маленький; карточка держится не на фото, а на отзыве.
- **Поля по порядку**: имя («Нелли К.») → рейтинг + число отзывов («4,99 · 76 отзывов») → бейдж **«Очень хвалят»** → **«Паспорт проверен»** с расшифровкой («Мы проверили копию паспорта: следы редактирования отсутствуют; имя, фамилия и фото совпадают») → оффер («Пробный урок бесплатно») → **развёрнутая цитата из отзыва клиента** → кнопка «Связаться».
- Доверие построено на трёх китах: верификация личности + агрегированный рейтинг + живая цитата клиента. Слотов/календаря на карточке нет — модель «откликнется на заказ».

Ссылка: https://profi.ru/repetitor/psihologia/web/

### Alma — helloalma.com

Публичный каталог с «бесплатной консультацией» как главным CTA:

- «You can browse our directory without providing any personal information» — каталог без регистрации, это позиционируется как фича.
- Фильтры: страховка, язык, **доступность по дням недели и времени суток**, идентичность терапевта, стиль терапии, специализации, очно/онлайн.
- Главный конверсионный механизм: **«Instantly book a free 15-minute consultation with an Alma therapist, with no commitment to start care»** — 15-минутное знакомство бронируется из профиля мгновенно.
- Платформенный сигнал: «97% of people seeing a therapist through Alma said that their therapist makes them feel seen and heard».

Ссылки: https://helloalma.com/how-it-works/, https://secure.helloalma.com/providers-landing/

### Headway — headway.co (частично: поиск закрыт от ботов, данные из help-центра)

- Пользователь выбирает страховку → фильтры вверху выдачи (локация, специализация, опыт, стоимость) → список подходящих провайдеров.
- В профиле два CTA: **«Schedule a phone consultation with ___ today»** над «Book now» — бесплатный телефонный контакт поставлен выше платной записи.
- Запись: выбрать время в календаре профиля → страховка → «Book now» → подтверждение на почту.

Ссылки: https://help.headway.co/hc/en-us/articles/4427474397332-Finding-a-provider, https://headway.co/therapists

### BetterHelp — betterhelp.com/therapists

Каталог существует только как SEO-каркас (города/штаты/темы); карточек с выбором нет — всё ведёт в анкету: «Match with a qualified therapist… in as little as 24 to 48 hours after completing a brief questionnaire». Доверие — только платформенные агрегаты: «4.9 out of 5 average rating from over 1.7 million client reviews», «30,000+ licensed therapists», «72 percent report symptom reduction within 12 weeks». Для mipsy это анти-референс по каталогу, но референс по формулировкам social proof.

Ссылка: https://www.betterhelp.com/therapists/

## Смежные каталоги людей

### Preply — preply.com (репетиторы)

Лучшая «продающая» карточка человека из просмотренных:

- **Сетка 2 колонки** на десктопе, карточка широкая и высокая.
- **Поля по порядку**: круглое фото (с **видео-превью** у части карточек) → имя + флаг страны → бейдж категории (**«Professional» / «Super Tutor» / «New tutor»**) → рейтинг + отзывы («4.9 · 41 reviews») → **цена за урок («$75»)** → **«23 active students» и «7340 lessons»** → языки → теги стиля («Goal-Focused») → заголовок-оффер от первого лица («Certified English Coach | Career, IELTS…») → сниппет описания → кнопки.
- **CTA прямо на карточке**: «Book trial lesson», «Send message», «View full schedule» — календарь в одном клике из выдачи.
- Фильтры — левый сайдбар: предмет, цена (слайдер), страна рождения, **«I'm available» (моя доступность по времени)**, специализации, второй язык, носитель, категории; сортировка «Our top picks».
- По клику на имя/фото — полный профиль.

Счётчики «N уроков / N активных учеников» — самый сильный сигнал «живого» специалиста: не самоописание, а следы реальной работы.

Ссылка: https://preply.com/en/online/english-tutors

### Toptal (+ бейджи Upwork)

- Toptal показывает людей каруселью карточек: круглое фото, имя, роль («Data Engineer»), **логотипы прошлых работодателей** (Oracle, Airbnb, Amazon, Tesla), бейдж «Verified Expert». Каталога нет — «Within days, we'll introduce you to the right Developer», доверие через жёсткость отбора: «Of the more than 200,000 people who apply… fewer than 3% make the cut».
- Upwork: система бейджей поверх выдачи — «Top Rated» (топ-10% фрилансеров), Job Success Score ≥90% на протяжении 13 из 16 недель. Бейдж — вычисляемый из истории заказов, а не покупаемый; алгоритм ранжирует надёжность выше цены.

Ссылки: https://www.toptal.com/developers, https://support.upwork.com/hc/en-us/articles/211063568-Understand-freelancer-talent-badges

### Airbnb (карточки листингов + профиль хоста)

- Карточка листинга: **«rounded photo, heart save toggle, price and rating, no card border or shadow»** — «The photo carries the card, so chrome is unnecessary»: без рамок и теней, глубину даёт сама фотография, скругление ~12–20px.
- Профиль хоста (Host Passport): фото обязательно, «clearly shows your face and genuine smile», + годы хостинга, средний рейтинг, верификация личности, отзывы, бейдж Superhost. Гость открывает его тапом по фото хоста на странице листинга.
- Перенос на людей: если фото — главный носитель карточки, вся остальная «обвязка» (рамки, тени, плашки) должна отступить.

Ссылки: https://superdesign.dev/blog/airbnb-design-system, https://hospitable.com/airbnb-profile, https://news.airbnb.com/an-update-on-identity-verification-on-airbnb/

## UX-исследования

### NN/g: Cards Component

- Карточки хуже списков там, где пользователь **сравнивает**: «card layouts typically deemphasize the ranking of content», карточки «less scannable than lists».
- Айтрекинг: «users look back and forth multiple times between items when they compare them» — поэтому раскладка полей должна быть жёстко одинаковой во всех карточках, каждое поле на своём месте.
- Для однородного контента (а каталог психологов однородный) NN/g прямо советует «consider using a standard vertical list».

Ссылка: https://www.nngroup.com/articles/cards-component/

### NN/g: Photos as Web Content

- Пользователи внимательно разглядывают **фото реальных людей** и полностью игнорируют стоковые: в кейсе FreshBooks люди тратили «10% more time viewing the portrait photos», чем на чтение длинных биографий рядом.
- «Users pay attention to information-carrying images» — фото специалиста в каталоге терапии и есть информация («подойдёт ли мне этот человек»), это аргумент за крупное фото.

Ссылка: https://www.nngroup.com/articles/photos-as-web-content/

### NN/g: Communicating Trustworthiness

Четыре фактора доверия: качество дизайна («professional appearance feels solid», опечатки убивают доверие), **прозрачность цен и условий заранее** (не прятать до чекаута), полнота и актуальность контента, связность с внешним миром (ссылки на независимые подтверждения — лицензии, реестры). Для каталога: цена и условия на карточке, а не «узнаете после записи».

Ссылка: https://www.nngroup.com/articles/communicating-trustworthiness/

### Baymard: превью в списках и фильтры

- Миниатюры в списках: «2 images were often not enough» — минимум 3 изображения на позицию (для товаров); для людей аналог — фото + видео/аудио как второй «ракурс» (Preply — видео, Alter — голос).
- **Горизонтальные панели фильтров непригодны при более чем 6–8 измерениях** — «Be Careful with Horizontal Filtering Toolbars»; при богатой фильтрации выигрывает сайдбар со счётчиками совпадений.
- Применённые фильтры показывать **дважды**: на своём месте в сайдбаре и сводкой над списком с крестиками удаления — сайты с обоими паттернами дают «vastly lower rate of user errors».

Ссылки: https://baymard.com/blog/secondary-hover-information, https://baymard.com/blog/horizontal-filtering-sorting-design

## Выводы для mipsy

Паттерны, которые повторяются у лучших:

1. **Фото — главный элемент карточки, и оно крупное.** Airbnb: «the photo carries the card»; NN/g: реальные лица разглядывают дольше, чем читают биографии. Запрос пользователя на крупные квадратные фото подтверждается: квадрат во всю ширину карточки, лицо занимает большую часть кадра, единый стиль съёмки/фона у всех специалистов. 56×56 — это паттерн Профи.ру, где карточку вытягивает отзыв, а не человек.
2. **Ближайший слот прямо на карточке — сильнейший CTA.** Zocdoc (3–6 кнопок-времён в выдаче), Ясно («12 слотов с 17 авг. 15:00»). У mipsy календарь уже центр модели — вынести «ближайшее время + число слотов» в каталог обязательно; это одновременно доступность, живость специалиста и повод кликнуть.
3. **Цена и опыт видны без клика.** «Сессия 50 мин 3 150 ₽» (Ясно), $/урок (Preply), ценовые диапазоны в фильтрах (PT). Прозрачность цены — фактор доверия по NN/g. Никаких «цена в профиле».
4. **Верификация — именной бейдж у имени, с расшифровкой.** «Диплом проверен» (Ясно), «Паспорт проверен» + что именно проверили (Профи), Verified (PT), Verified Expert (Toptal). Для mipsy: бейдж «Диплом проверен» / «Проверен МИП» с тултипом о процедуре — дешёвый и честный сигнал, доступный с первого дня.
5. **Голос человека работает лучше списка регалий.** Личное заявление 2–3 предложения (Psychology Today), заголовок-оффер от первого лица (Preply), цитата клиента (Профи), аудио «голос психолога» (Alter). На карточке mipsy нужна одна строка от первого лица («С чем я помогу»), а не только подход+темы.
6. **Люди — это список/2 колонки, не плотная сетка.** PT и Zocdoc — вертикальный список, Preply — 2 колонки, Ясно — крупные карточки. NN/g: при сравнении пользователи прыгают взглядом между позициями — карточки должны быть широкими, с жёстко одинаковой раскладкой полей. Текущие 3 колонки mipsy — товарная плотность; при крупном фото переход на 2 колонки произойдёт естественно.
7. **Счётчики реальной работы вместо самопохвалы.** «7340 lessons / 23 active students» (Preply), «615 000+ сессий» (Alter, на уровне платформы), эндорсменты коллег (PT). На старте у mipsy честны только «опыт N лет» и образование на карточке + агрегаты платформы на лендинге; счётчик «N сессий на mipsy» включать, когда появятся реальные числа.
8. **Фильтры: чипы сверху — только пока измерений мало.** Baymard: горизонтальная панель ломается после 6–8 измерений. Сейчас у mipsy 3 фильтра — чипы сверху корректны; при росте (цена, метод, время, формат) — переход на сайдбар + сводка применённых фильтров над списком. Отдельно стоит украсть фильтр «время сессии» (Alter, Alma) — он конвертирует лучше абстрактных.

Анти-паттерны:

- **Мелкий аватар + плотная сетка** — человек превращается в позицию прайс-листа (текущий каталог mipsy, Профи.ру).
- **Покупной/непрозрачный рейтинг** — топ-100 B17 «покупается», и пользователи это знают; рейтинг без понятного происхождения вредит сильнее его отсутствия.
- **Выдуманные агрегаты** («125 000 человек» у PsyPsy — уже помечено в psypsy-landing.md) — на старте social proof заменять честной верификацией.
- **Перегруз темами**: не 10 чипов, а 3–4 + «и ещё N» (Ясно).
- **Клик по слоту = сразу запись без знакомства** (Zocdoc) — для терапии слишком резко; правильный порядок mipsy: клик по карточке → профиль, клик по слоту → запись, как у Ясно.
- **Каталог за регистрацией** — Alma прямо продаёт обратное («browse without providing any personal information»); каталог mipsy должен оставаться полностью публичным.
- **Скрывать доступность** — карточка без слотов/«ближайшего времени» вынуждает кликать вслепую и умирает в сравнении с соседями, у которых слот виден.
