# PsyPsy — разбор анкеты-квиза (rocketlauncher)

Снято 2026-08-11 из HTML страницы анкеты (передан пользователем). Референс для клиентской анкеты mipsy: «при регистрации пользователя нужно сделать аналогичный тест».

## Общая механика

- **Один вопрос на экран**, горизонтальный слайд между экранами, кнопка «Предыдущий вопрос» в шапке.
- **Прогресс-бар**: проценты + 4 сегментные линии; проценты захардкожены под каждую ветку.
- **Одиночный выбор продвигает вперёд автоматически**; мультивыбор и текстовые поля — через кнопку «Продолжить».
- **Подсказки под вопросами** — успокаивающие факты («Женщины и мужчины в равной степени нуждаются в поддержке», статистика ИП РАН) — снижают отвал.
- Ответы **копятся на клиенте** (массив rocketlaucherdata) и отправляются на сервер пачкой перед регистрацией; атрибуция «откуда узнали» уходит сразу по клику.
- **Регистрация в самом конце** (эффект вложенных усилий): имя/псевдоним + email + чекбокс ПД. Входа по паролю нет — код на почту. После регистрации редирект на `/payment-new/`.
- A/B-тест групп (test_group), Яндекс.Метрика reachGoal `enter_email`.

## Ветвление

Первый вопрос «Кому нужна поддержка?» делит анкету на 3 ветки: **для себя / для пары / для ребёнка**.

### Ветка «Мне лично» (~28 экранов)

1. Пол (Ж / М / не хочу отвечать)
2. Возраст (селект 15–100)
3. Опыт терапии (нет / краткосрочная / длительная)
4. Псевдотест: симпатичный цвет (8 плашек)
5. Псевдотест: приятный мужской портрет (4 фото)
6. Псевдотест: приятный женский портрет (4 фото)
7. Основная проблема (депрессия / тревога-стресс / самооценка / отношения / детская травма / утрата / выгорание / другое)
8. Физическое здоровье (хорошо / средне / плохо)
9. Грусть, тоска, подавленность сейчас? (да / нет)
10–15. Частотная шкала «никогда → каждый день»: заторможенность/возбуждение, подавленность, сон, усталость, пищевое поведение, концентрация
16. **Мысли причинить себе вред** — та же частотная шкала. Кризисной ветки нет: просто следующий вопрос
17. Переживания интимного плана (да/нет)
18. Панические атаки (да/нет)
19. Фобии (да/нет)
20. Насколько состояние мешает повседневной жизни (4 ступени)
21. Тип занятости (9 вариантов)
22. Формат общения (телефон/видео, чат+видео, определюсь позже)
23. Возраст психолога (от 40 / до 40 / любой)
24. Пол психолога (М / Ж / не важно)
25. Предпочтения по подходу? (нет/да) → условный экран: 17 подходов + «Пропустить»
26. Откуда о нас узнали (12 вариантов, «другое» — с текстовым полем)
27. Особые запросы — мультивыбор из 19 тем (депрессия, зависимости, утрата, пищевые расстройства, гнев, БАР…)
28. **Свободное поле «Почему вы идёте в терапию?»** — счётчик слов + прогресс-бар с градиентом красный→зелёный, норма ~30 слов; кнопка заблокирована при пустом поле
29. Регистрация (имя + email + ПД) → код на почту → оплата

### Ветка «Для пары» (короче)

Цели консультаций (мультивыбор 16), пол, тип отношений, живёте ли вместе, **домашнее насилие (да/изредка/нет)**, возраст/пол психолога, атрибуция, свободное поле, регистрация.

### Ветка «Для ребёнка»

Пол ребёнка, кем приходитесь (родитель/приёмный/опекун), возраст 7–18, с кем живёт, учёба, опыт терапии, здоровье/сон/питание/панические атаки/концентрация, попытки самоповреждения, проблемы (мультивыбор 7), отношения с ребёнком, пол психолога, атрибуция, свободное поле, регистрация.

## Выводы для mipsy

**Берём:**
- Формат «один вопрос на экран» + прогресс + кнопка назад + автопродвижение на одиночном выборе.
- Успокаивающие подсказки под чувствительными вопросами.
- Свободное поле с мягкой мотивацией написать больше (счётчик слов) — это главный материал для оператора при подборе.
- Контакты и согласие ПД в самом конце, после вложенных усилий.
- Ветвление с первого вопроса (в MVP можно оставить одну ветку «для себя», остальные — «скоро»).
- Предпочтения к специалисту (пол/возраст) — просто и полезно оператору.

**Не берём / делаем иначе:**
- Контакт mipsy — **телефон**, не email (решение: основа — телефон, связь через оператора). Email опционален.
- После анкеты у нас **не оплата**, а «оператор свяжется» / выбор слота — по нашей воронке.
- **Вопрос о самоповреждении без реакции — неприемлемо.** У нас решено: кризисная ветка с экстренными контактами при тревожных ответах.
- Псевдотест «цвет/портреты» — сомнительная механика (визуальный подбор «приятного» специалиста); под вопросом.
- 17 подходов на выбор — слишком много для новичка; у PsyPsy же на лендинге написано «не нужно разбираться в подходах». Либо убрать, либо «есть предпочтения?» с полем.
- Атрибуцию «откуда узнали» в прототип не тащим (некому анализировать), добавить позже.
