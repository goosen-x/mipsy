# Дизайн-система mip.institute (МИП)

Снято 2026-08-12 из CSS сайта (Next.js, ~630KB стилей). По ней стилизован прототип mipsy («нужно сделать аналогично»).

## Шрифты

- **Mulish** — основной (105+ упоминаний), sans-serif, есть кириллица в Google Fonts.
- Stem — акцидентный (платный, не берём), Jost — точечно.

## Цвета (по частоте в CSS)

**Фиолетовая гамма (основная):**
- `#6f01c6` — глубокий фиолетовый, основной цвет кнопок/акцентов (background-color кнопок, бордеры)
- `#855edf`, `#8f60ff`, `#947aff`, `#9a6ffc`, `#b250ff` — светлее, ховеры/градиенты
- `#faf5ff`, `#f6f4ff`, `#e7dffa`, `#e7dff9` — светлые фиолетовые фоны секций

**Оранжевый акцент:**
- `#f87e1b` (основной), `#ff8f52` (светлый), `#fd521b` — CTA-элементы, маркеры, рамки карточек

**Нейтральные:** текст `#1a1a1a`/`#212121`, фоны `#f4f4f4`/`#fcfcfc`, серые `#b3b3b3`, `#d9d9d9`.

## Форма

- Радиусы: кнопки **5px** (.3125rem), карточки **10px** (.625rem), крупные блоки 16–30px.
- Кнопка МИП: `border-radius:5px; border:1px solid #6f01c6; padding:14px 40px; font-size:12px`.
- Фирменный градиент: `linear-gradient(120deg, #947aff, #6f01c6)`.
- Тени лёгкие: `0 4px 12px rgba(...,.25)`.

## Типографика

Базовый текст 1rem/.875rem; заголовки 2.75rem / 1.875rem / 1.625rem.

## Перенос на mipsy

- Шрифт: Inter → **Mulish** (latin + cyrillic).
- Палитра brand-* : зелёная → фиолетовая шкала вокруг `#6f01c6`; светлые фоны `#faf5ff`/`#e7dffa`.
- Акцент для главных CTA — оранжевый `#f87e1b` (как у МИП).
- Радиус базовый 10px, кнопки без rounded-full.
- Тёмные блоки — фирменный градиент `120deg, #947aff → #6f01c6`.
